🚀 Installatie

Volg deze stappen voor lokale installatie:

Clone de repository

git clone https://github.com/Revin400/Web_app_development_2526.git


Frontend dependencies installeren

npm install


Backend openen in Visual Studio

Open Web_app_development_2526.sln in Visual Studio.

Build & run de applicatie.

Zorg ervoor dat je .NET en Node.js geïnstalleerd hebt.

🛠️ Hoe te gebruiken

Afhankelijk van de technologie-stack:

Frontend

Wijzig de HTML, CSS en frontend JavaScript/TypeScript code.

Implementeer UI-componenten of logica gebaseerd op de requirements uit de PDF-documentatie.

Backend

Pas server-logica aan via de Visual Studio solution.

Zorg dat routes en API-endpoints correct samenwerken met frontend.
